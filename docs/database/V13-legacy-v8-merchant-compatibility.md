# V13 旧 V8 商家迁移兼容

迁移文件：`database/V13__legacy_v8_merchant_compatibility.sql`。

部分开发环境曾执行旧 `V8__audit_log_view_permission.sql`，而当前正式序列的 V8 已用于商家、店铺和客服表。V13 使用幂等 DDL 和权限种子补齐商家结构；启动迁移器仅在发现旧 V8 且尚未执行 V13 时关闭一次迁移前校验，执行 V9～V13 后调用 Flyway `repair` 对齐 V8 描述和校验和，并立即重新严格校验。

兼容过程不删除表、不清空数据，也不要求重建数据库。全新数据库和已经执行商家版 V8 的数据库仍按 V1～V13 正常迁移，V13 只执行幂等核对。V13 一旦在任何环境执行，不得再修改脚本内容；后续结构变化必须新增更高版本迁移。

迁移在 Spring 单例初始化阶段完成，早于定时任务和业务 Runner，避免首次启动时订单定时任务访问尚未创建的表。
